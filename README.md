## 初始开发/构建环境

## 依赖

- Node.js 22.17+
- pnpm 10.13+
- .NET Core 8.0 SDK

```bash
# 拉取仓库
git clone https://github.com/FurryRbl/ThaumaturgySpectacle.git

cd ThaumaturgySpectacle

# 安装依赖
pnpm install --frozen-lockfile
```
