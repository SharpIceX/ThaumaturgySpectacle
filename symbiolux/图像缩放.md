# 关于图像缩放

本文中会使用到 `ffmpeg`。

我一直有个问题很苦恼。我希望找到一个自我感觉合适的图像缩放算法，主要有无损和高质量为主。

在我测试了多种算法和配置后我得到了一个令我满意的配置：

```bash
ffmpeg -i $Image_Path -vf "scale=256:256:flags=bicubic" -pix_fmt rgba -map_metadata -1 -pred mixed -c:v png -q:v 1 $Image_output
```

参数解释：

| 参数 | 说明 |
| ------------- | ----------------------------------- |s
| scale=256:256 | 缩放到 256x256，或其他大小 |
| flags=bicubic | 使用「bicubic」算法，又叫为双三次插值 |
| -pix_fmt rgba | 设置像素格式为 RGBA |
| -map_metadata -1 | 不保留元数据 |
| -pred mixed | 使用混合预测 |
| -c:v png | 设置视频编码器为 PNG |
| -q:v 1 | 设置视频质量为 1，表示最高质量 |
