# 幻术奇象 Open Graph Banner 设计

使用 [Inkscape](https://inkscape.org/) 进行设计和编辑。

## 依赖字体

本工程需要使用 [LXGW WenKai / 霞鹜文楷](https://github.com/lxgw/LxgwWenKai) 字体，该字体采用 [OFL-1.1](https://github.com/lxgw/LxgwWenKai/blob/main/OFL.txt) 许可。

> [!IMPORTANT]
> 需自行下载安装字体，方可正确显示 svg 内容。
